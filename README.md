# arduino-traffic-light
A simple Arduino traffic light project using red, yellow, and green LEDs to simulate a real traffic light sequence.

A simple Arduino project that simulates a traffic light using red, yellow, and green LEDs.

## What It Does

The LEDs turn on in sequence to simulate the operation of a real traffic light.

## Components Used

Arduino Uno, red LED, yellow LED, green LED, resistors, breadboard, and jumper wires.

## How It Works

The Arduino controls the three LEDs using digital output pins. Each light turns on for a specific amount of time before switching to the next light.

## What I Learned

I learned how to control multiple LEDs with Arduino, use digital output pins, add timing with delays, and build a simple traffic light circuit.
